개인정보처리방침

시행일: 2026년 9월 15일

한눈에 보기 — 휴가요정은 로그인 없이 쓸 수 있고, 이때 입력한 휴가 설정은 이용자의 브라우저에만 저장됩니다. 서비스 개선을 위해 개인을 알아볼 수 없는 익명 이용 통계를 모으며, 회원가입을 선택한 경우에만 계정 정보를 보관합니다.

1. 수집하는 정보

① 로그인 없이 이용할 때

남은 연차, 회사 휴가제도, 찜한 휴가 조합 등 입력하신 내용은 이용자 기기의 브라우저 저장소 (localStorage)에만 저장되며 서버로 전송하지 않습니다.

② 익명 이용 통계 (모든 이용자)

어떤 기능이 쓰이는지 파악해 서비스를 개선하기 위해 아래 항목을 기록합니다.

항목설명
방문자 ID · 세션 ID브라우저가 무작위로 만든 식별자. 이름·이메일 등과 연결되지 않습니다.
이용 기록방문한 화면 경로, 사용한 기능(예: 계산 시작, 연도 선택, 공유)
휴가 계산 정보선택한 연도, 입력한 연차 일수, 휴가 스타일, 추천 결과의 휴식일 수
유입 경로이전 사이트의 도메인(주소 전체가 아닌 도메인만), 광고·캠페인 태그(UTM)
기기 구분화면 너비로 판단한 모바일 / 태블릿 / 데스크톱

이 통계에는 이름, 이메일, 전화번호, IP 주소, 정확한 위치, 브라우저 지문(fingerprint)을 저장하지 않습니다.

③ 회원가입을 선택한 경우

  • 이메일로 가입: 이메일 주소, 이름(입력한 경우), 비밀번호(암호화되어 저장되며 운영자도 볼 수 없음)
  • 구글로 가입: 구글이 제공하는 이메일 주소, 이름, 프로필 사진 주소
  • 공통: 여러 기기에서 이어 쓰기 위해 동기화한 휴가 설정

2. 이용 목적

  • 휴가 일정 추천 기능 제공
  • 회원의 휴가 설정을 여러 기기에서 이어 쓸 수 있도록 동기화
  • 서비스 이용 현황 분석 및 개선

수집한 정보를 판매하거나, 위 목적 외의 용도로 쓰지 않습니다.

3. 보관 기간과 삭제

  • 브라우저에 저장된 설정: 이용자가 브라우저의 사이트 데이터를 지우면 즉시 삭제됩니다.
  • 회원 정보와 동기화된 설정: 회원 탈퇴 시까지 보관합니다. 탈퇴를 원하시면 아래 문의처로 요청해 주세요. 확인 후 지체 없이 삭제합니다.
  • 익명 이용 통계: 개인을 알아볼 수 없는 형태로, 서비스 개선에 필요한 기간 동안 보관합니다. 방문자 ID는 브라우저 저장소를 지우면 새로 만들어져 이전 기록과 연결되지 않습니다.

4. 처리를 맡기는 곳

서비스 운영을 위해 아래 업체의 인프라를 이용합니다.

업체맡기는 일
Supabase회원 인증, 동기화된 설정 및 익명 통계 저장
GitHub (GitHub Pages)웹사이트 호스팅

위 업체들은 보안과 서비스 운영을 위해 접속 기록(IP 주소 등)을 각 사의 정책에 따라 일시적으로 남길 수 있습니다. 휴가요정의 통계 데이터베이스에는 IP 주소를 저장하지 않습니다.

5. 브라우저 저장소 사용

휴가요정은 쿠키 대신 브라우저 저장소(localStorage·sessionStorage)에 입력한 설정, 로그인 상태, 무작위 방문자 ID를 저장합니다. 브라우저 설정에서 사이트 데이터를 삭제하면 모두 지워집니다. 이 방침은 광고나 외부 분석 도구를 도입하면 그 내용을 반영해 갱신합니다.
